# Real Estate Price Prediction

## Overview

Machine learning project focused on real estate price prediction using multivariate regression. The objective was to develop a predictive model capable of estimating property prices based on multiple features.

## Context

Developed as part of an academic project at the Federal University of Rio de Janeiro (UFRJ), within the Electronics and Computer Engineering undergraduate program.

## Methodology

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature analysis and selection
- Multivariate regression modeling
- Model training
- Model evaluation

## Results

The project includes price predictions generated by the regression model based on the test dataset, organized in a submission file.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
